# Сложно сосредоточиться

Адаптивная верстка учебного проекта Яндекс Практикума в светлой, темной и авто-теме.

## Что внутри

- HTML-разметка
- CSS на переменных, grid и media queries
- Переключение тем через JavaScript
- Адаптив под мобилку, планшет и десктоп

## Структура

- `index.html` — основная страница
- `styles/` — стили и темы
- `scripts/` — логика переключения темы
- `images/` — изображения и иконки
- `fonts/` — шрифты
